- **Relational Data Modeling:** Multi-table relational architecture linking `Users`, `Rooms`, `Bookmarks`, and `Reviews` with strict cascading integrity (`ON DELETE CASCADE`) and composite keys.

- **Enterprise Configuration:** Strongly-typed environment management using **Pydantic BaseSettings** to prevent secret leakage.
