### 🚀 Featured Projects

#### ⚡ [RentSphere — Smart Room & Flatmate Finder API](https://github.com/anubhavpaul753-spec/RentSphere-Smart-Room-Flatmate-Finder-API)
> *A production-grade REST API engineered for student housing discovery, room listing, and flatmate compatibility.*

* **Relational Data Architecture:** Normalized schema modeling linking `Users`, `Rooms`, `Bookmarks`, and `Reviews` with composite primary keys and cascading integrity (`ON DELETE CASCADE`).
* **Automated Migrations & Security:** Version-controlled database schema revisions powered by **Alembic**, with JWT-based Bearer authentication and Bcrypt password hashing.
* **Type Safety & Configuration:** Strongly-typed serialization using **Pydantic** with centralized environment security via **BaseSettings**.
* **Tech Stack:** `FastAPI` • `PostgreSQL` • `SQLAlchemy 2.0` • `Alembic` • `JWT Auth` • `Pydantic`
